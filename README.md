# 📊 Retail Sales Performance Dashboard

## 📝 Short Description

An interactive **Power BI Retail Sales Performance Dashboard** designed to analyze sales, stock, cost price, product categories, brands, and state-wise performance. The dashboard provides clear and visual insights to support better business decision-making.

## 🎯 Purpose

* Analyze overall retail sales performance
* Monitor total selling price and stock
* Compare cost prices across product categories
* Analyze brand-wise selling prices
* Understand state-wise performance
* Present business insights through interactive visualizations

## 🛠️ Tech Stack

* **Power BI** – Dashboard development and visualization
* **Power Query** – Data cleaning and transformation
* **Microsoft Excel** – Data source and data preparation

## 📂 Data Source

**Microsoft Excel** – Retail sales dataset containing information about products, categories, brands, prices, stock, quantity, sales, and state-wise data.

## ✨ Features & Highlights

* 📌 Total Selling Price KPI
* 📦 Total Stock KPI
* 📊 Cost Price by Category analysis
* 🌎 State-wise Unit Price analysis
* 🍩 Quantity and Total Sales donut chart
* 🏷️ Brand-wise Selling Price analysis
* 📈 Cost Price and Brand performance gauge
* 🎨 Interactive and visually organized dashboard
* 🔍 Easy-to-understand business insights

## 📊 Dashboard Insights

The dashboard helps identify high-performing product categories, compare selling and cost prices, understand stock levels, and analyze sales distribution across different states and brands.
